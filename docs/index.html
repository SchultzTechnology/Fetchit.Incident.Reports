2026-08-18 Resolved

Cert-Manager Webhook CA Expiry — Cluster-Wide TLS Renewal Failure

All Let's Encrypt certificate renewals silently blocked for 46 days due to expired cert-manager internal webhook CA. Detected when k8sapi.fetchitdata.cloud TLS cert expired, causing Orion "View Logs" to return "Failed 0". Five certificates renewed immediately on fix. Near-miss: broker cert was days from expiry, which would have repeated the July 5 cascade.
2026-07-05 Resolved

Ingress Controller — Full Production Outage

All production services (orion, cleartext, broker, missedcalls) unreachable for ~4h 40m due to zero running ingress controller pods. Caused by a chain of failed image registry migrations from marketplace.azurecr.io → registry.bitnami.com (DNS unresolvable). Resolved by switching to registry.k8s.io/ingress-nginx/controller:v1.1.1 and correcting pod security context. Concurrent RingCentral NullReferenceException also patched.

AKS Node Starvation — Kubelet Eviction Event

102 pods on a 2-core VM reached 273% CPU limit overcommitment, starving the kubelet of CPU cycles and triggering a TaintManagerEviction. Node self-recovered. Structural changes required to prevent recurrence.
2026-06-26 Resolved

Lookup Service — MQTT Message Processing Delay

Production calls delayed up to 2.5 minutes due to serial MQTT message handling. Root cause: MQTTnet managed client awaiting each handler sequentially. Fixed by decoupling dispatch from processing using Task.Run with manual acknowledgement.
